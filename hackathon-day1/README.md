# CLI Calclator

## Instruction on how to run.

* The program is to be run using the stadard go command "go run main.go"

* It then askes the user to choose an operation between "addition", "subtraction", "multiplication", "division", "Help" and "Exit" to use for the computation.

* If the user chooses Help, it displays a list of commands and what to choose for the operation and if the user chooses "Quit", it exits from the program.


* After that, it asks the user for first and second digit numbers respectively and uses them to perform the operation.
